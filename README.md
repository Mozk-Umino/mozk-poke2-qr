# ポケポケ デッキQR

ポケポケ（Pokémon Trading Card Game Pocket）のデッキを作って、ゲームの「コードを読み取る」で読み込めるコードを表示する、非公式のファンツールです。

**▶ https://mozk-umino.github.io/mozk-poke2-qr/**

## できること

- カードを名前で探してデッキを組み、ゲームで読み込めるコードを表示する
- ChatGPT や Claude に貼るプロンプトをコピーして、AI と相談しながらデッキを作る（Claude 用のスキルもあります）
- デッキを URL で共有する（開いた人にも同じコードとデッキ一覧が出る）
- ブログ・SNS 用に、デッキ一覧とコードをまとめた画像や、Markdown / HTML を出力する
- ゲームのコードの中身から、どんなデッキかを表示する

## 使い方

1. ページの「デッキを作る・直す」で、カードを検索して「＋」で追加し、エネルギーを選ぶ（AI に作ってもらう場合は「使い方」の「プロンプトをコピー」）
2. 20枚そろうとコードが出る
3. ゲームで「マイデッキ」→「新規作成」→「コードを読み取る」
   - スマホだけのとき: 「QR画像を保存」して、保存した画像から読み取る
   - PC があるとき: PC に出したコードをスマホのカメラで読む

## Claude 用スキル

Claude を使っている人は、スキルを入れておくと、デッキの相談の最後に Claude がデッキURLを出してくれます（プロンプトを毎回貼る必要がありません）。

1. [pokepoke-deck-url.zip](https://mozk-umino.github.io/mozk-poke2-qr/skill/pokepoke-deck-url.zip) をダウンロードする
2. claude.ai の「設定」→「機能」→「スキル」から、zip をそのままアップロードする
3. 会話で「ポケポケのデッキを相談したい」などと話しかける

- 「設定」→「機能」で**コード実行**を有効にしておくと、Claude がカード番号をカード一覧と照合してからURLを出します
- スキルの中身は [skill/pokepoke-deck-url/](skill/pokepoke-deck-url/) にあります

## デッキURLの書き方

```
https://mozk-umino.github.io/mozk-poke2-qr/?n=ミライドンex&e=雷&d=B1a-24x2.A1-98x2.B1a-26.B3a-19x2.A3a-21x2.PROMO-A-7x2.B3a-73.B1-225.A2-150.B1-226.B1a-68.A1-225.PROMO-A-5x2.A2-147
```

| パラメータ | 中身 |
|---|---|
| `n` | デッキ名（省略可） |
| `e` | エネルギー。漢字1文字を続けて書く（草 炎 水 雷 超 闘 悪 鋼 から1〜3種類） |
| `d` | カードを `.` でつなぐ。`セット-番号`、2枚なら末尾に `x2` |
| `c` | `d`・`e` の代わりに、ゲームのコードの中身（Base64）をそのまま入れてもよい |

セットと番号はカード左下の収録記号です。同じ名前でも弾によって効果が違うカードがあり、どのカードになるかは番号で決まります。

## 注意事項

- **ドラゴン・無色エネルギーは選べません。** ゲームのエネルギー選択にないためです
- **レアリティ・イラストは指定できません。** コードに入るのはカードの種類だけで、読み込むと手持ちの絵柄になります
- **新弾のカードは少し遅れて使えるようになります。** 有志のカードDBに追加されるまでは使えません
- **カード名の日本語は非公式の表記です。** 攻略サイトの表記で確認していますが、新弾のカードなどで確認が済んでいないものは、ページで「推測」と表示します
- **非公式のツールです。** ゲームのアップデートで、作ったコードが読み込めなくなる可能性があります
- 入力したデッキはブラウザの中だけで処理し、どこにも送信・保存しません
- 利用状況を知るために Google アナリティクスで閲覧数とボタンの利用回数を数えています（Cookie を使います。デッキの内容は送りません）

## しくみ

QRの中身はBase64文字列で、デコードするとこうなる（数値はビッグエンディアン）。

```text
u8  トレーナーズ枚数
u24 トレーナーズのID + 10,000,000 （枚数ぶん）
u8  ポケモン枚数
u24 ポケモンのID （枚数ぶん）
u8  エネルギー種類数
u8  エネルギー種類 （1草 2炎 3水 4雷 5超 6闘 7悪 8鋼）
```

- IDはカードの種類ごとの番号で、イラスト違いは同じID（読み込んだ側の手持ちのイラストになる）
- QRはバージョン9・誤り訂正H（ゲームが表示するものと同じ）
- セット番号とIDの対応は [flibustier/pokemon-tcg-pocket-database](https://github.com/flibustier/pokemon-tcg-pocket-database) の `cards.min.json` をページを開いたときに取得する。新弾はDB側の更新で使えるようになる
- 形式の解析は [KevinGutowski/tcgp-deck-qr](https://github.com/KevinGutowski/tcgp-deck-qr)（MIT）による。テストで、同プロジェクトで実機読み込みが確認されたデッキと同じコードが出ることを確かめている

開発・運用の手順は [docs/MAINTAINING.md](docs/MAINTAINING.md) にあります。
